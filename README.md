# Project Description

A Chess game engine with the usage of pygame frontend and a C++ backend with usage of pybind library for binding C++ with python.

# Installation and running

Run the following commands in your terminal

```bash
git clone https://github.com/Secreton456/Chess-Engine.git Chess_Engine
cd Chess_Engine
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
make
python3 main.py
```
